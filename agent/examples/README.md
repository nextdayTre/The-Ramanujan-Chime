# Generated agent examples

One committed success envelope per tool, generated by
`node scripts/gen-agent-artifacts.mjs` from the shared registry
(`js/agent-core.js`). Do not hand-edit; verify with `--check`.

Each file is `{ ok, schemaVersion, tool, data, deeplink, warnings }`
exactly as the CLI `--json` output and the MCP `tools/call` text content.

- `manifest.json` — tool `manifest`, args `{}` — Envelope whose data is the full capability manifest (read this first without a server).
- `build_deeplink.json` — tool `build_deeplink`, args `{"preset":5,"tab":"harmonics","static":true}` — Canonical link for the Analytic Morlet patch on the harmonics tab.
- `analyze_patch.json` — tool `analyze_patch`, args `{"preset":12}` — Default Four-Bit Orbit patch: shell metrics, zone histogram, stats, 5 probe points.
- `eval_point.json` — tool `eval_point`, args `{"preset":12,"t":0.25}` — Playhead point at t=0.25 with float32 bits, twins and telemetry.
- `bit_inspect.json` — tool `bit_inspect`, args `{"value":3.141592653589793}` — π as float32: hex 0x40490FDB.
- `discrete_group.json` — tool `discrete_group`, args `{"orderN":12,"stride":3}` — Composite N=12, stride 3: gcd 3, 4-state subgroup.
- `ramanujan_pi.json` — tool `ramanujan_pi`, args `{"maxK":2}` — Ramanujan 1/π vs Fourier odd harmonics convergence.
- `fourbit_orbit.json` — tool `fourbit_orbit`, args `{"R":1,"playT":0.25}` — θ=90°: 1111/F apex, 8↔1 equatorial pair, Quadray tetrahedron.
- `frobenius_secp.json` — tool `frobenius_secp`, args `{"k":4}` — secp256k1 Frobenius trace S_4 and exact point count #E(F_p^4).
